# Autonomous Embedded Control Unit (AECU)

An advanced modular embedded control system project developed using C++.

The project explores automotive-inspired electronic control unit architectures, real-time processing, sensor management and fault detection.

## Architecture

- Sensor Management
- Signal Processing
- PID Control
- Fault Detection
- Safety Management
- System Telemetry

## Technologies

- C++17
- Embedded Systems Architecture
- Real-Time Systems Concepts
- PID Control
- Sensor Data Processing
- Fault Management

## Main Features

- Modular software architecture
- Sensor data acquisition simulation
- Moving average filtering
- PID control algorithm
- Fault detection mechanisms
- Safe mode management
- System telemetry
